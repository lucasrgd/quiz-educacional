# Quiz Educacional com Ranking 🎓

Este é um projeto educacional feito com Python, usando Tkinter e SQLite.

## Funcionalidades

- Perguntas de múltipla escolha
- Cálculo de pontuação
- Ranking com top 10 jogadores
- Banco de dados com SQLite
